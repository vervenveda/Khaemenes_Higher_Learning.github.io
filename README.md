## Overview

**Khaemenes Higher Learning** is the university-level division of the Khaemenes Academy educational network.

It is designed as an **ever-expanding federated university**, not a single-repository course warehouse.

The Higher Learning repository serves as the central university campus, catalog, student entry point, academic directory, pathway organizer, and future records/credential hub. Individual schools, conservatories, institutes, laboratories, libraries, and specialist departments may remain in their own Verve N Veda repositories when that gives the subject stronger source ownership and room to grow.

A course does **not** need to be physically stored in this repository to belong academically to Khaemenes Higher Learning.

---

# The Federation Principle

Higher Learning separates two ideas:

1. **Academic relationship** — where a course belongs in the university.
2. **Source ownership** — which repository actually owns and maintains that course, hall, laboratory, archive, or specialist program.

Higher Learning should **catalog, connect, route, and contextualize** source-owned programs.

It should not duplicate them unless a deliberate migration is approved.

This prevents:

- stale copies;
- conflicting course authority;
- duplicate Mentor records;
- broken update paths;
- unnecessary repository growth.

# Course-Bearing Halls

A **Hall** is an academic container when it contains structured courses, modules, assessments, projects, or mastery pathways.

A Hall may live inside a specialist repository and still belong to the Higher Learning university catalog.

Example:

```text
Khaemenes Higher Learning
  → School of Health & Medical Studies
    → Medicament Hub
      → Traditional Medicine Hall
        → structured course modules
        → quizzes
        → research studio
        → mastery progression
```

Higher Learning should surface the Hall academically while preserving the Hall's original repository and URL.

# Complete Repository Visibility

Higher Learning should list **every public repository in the Matrix**, even when a repository is not an academic department.

The complete repository directory exists for:

- transparency;
- discovery;
- research;
- cross-campus navigation;
- institutional memory;
- technical provenance.

Being listed in the directory does **not** automatically make a repository a degree program or Mentor recommendation.

Each repository retains its own classification and source authority.

The Higher Learning landing page uses the central ecosystem registry generated by the Mentor discovery system. That registry spans the Matrix accounts and can grow as repositories are added.

Private repositories are not intentionally exposed by the public university directory.

---

# Automatic Expansion

Higher Learning is not meant to have a final fixed list.

The public network catalog should read the central registry:

`assessment-engine/mentor/registry/ecosystem-repositories.json`

When a new public repository is discovered by the Matrix registry, the university network directory can display it automatically.

Curated academic roles remain separate from automatic repository discovery.

This means:

- **automatic layer:** every public repository;
- **curated layer:** schools, conservatories, halls, departments, libraries, laboratories, institutes, services, and feeder campuses.

---

# Mentor / NAIB Relationship

The Higher Learning catalog and Mentor federation serve different purposes.

### Higher Learning catalog

- establishes academic relationships;
- presents university schools and programs;
- connects distributed course halls;
- provides student-facing navigation;
- lists the full institutional network.

### Source-owned Mentor manifests

- establish repository authority;
- expose verified recommendable resources;
- preserve stage, preference, learner, freshness, and high-stakes metadata;
- prevent Higher Learning from falsely claiming ownership of distributed resources.

Therefore, the Higher Learning `mentor-manifest.json` should list **only resources that Higher Learning directly owns**.

Federated schools remain represented by their own source manifests.
