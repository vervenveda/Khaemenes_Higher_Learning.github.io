Module 1 — Coding Foundations

Welcome to your very first coding adventure! Work through each lesson below. When you finish all the cards, the quiz will appear.

1 — What Is a Computer?

A computer is a helper that follows exact directions. If you say “Make a sandwich” but never explain how, it just sits there!

Computers need clear step-by-step instructions. Those steps are called code.

2 — What Is Code?

Code is a special language made of words, numbers, or pictures that tell the computer what to do. Binary uses 0 and 1's. You are about to become a coder — someone who teaches computers!

3 — Everyday Algorithms

An algorithm is a list of steps that solve a problem — like a recipe! Arrange the sandwich steps in order:

  • 🥪 Eat sandwich
  • 🍞 Put peanut butter on bread
  • 🍞 Take out two slices of bread
  • 🥜 Open the peanut butter jar

4 — Sequencing & Debugging

Sometimes steps are mixed up — that’s a bug. Fixing it is called debugging!
Click “Run Broken Code” to see why order matters.

5 — Loops

A loop repeats an action. Click Play to watch a loop draw colored dots!

Module 2 — Block Coding Logic

1 — What Is Block Coding?

Instead of typing code letters, we can drag colorful blocks that fit together like puzzle pieces. Each block tells the computer to do one thing.

It’s an easy way for beginners to see how code fits together!

2 — Events Start Actions

Blocks often begin with an event — something that happens like clicking a button or pressing a key. Try clicking the cat!

Module 3 — Web Basics (HTML + CSS)

Discover how websites are built and styled!

1 — What Is a Website?

A website is a group of pages that live on the internet. Each page is made from code that the browser reads and shows to us.

We use HTML to build the structure and CSS to make it colorful and stylish.

2 — HTML: The Structure

HTML stands for HyperText Markup Language. Tags like <h1> and <p> tell the browser “this is a heading” or “this is a paragraph.”

Think of HTML as the skeleton of your page.

3 — CSS: The Style

CSS stands for Cascading Style Sheets. It changes colors, fonts, sizes, spacing, and more.

If HTML is the skeleton, CSS is the clothes and decorations that make your page beautiful.

4 — Try It Yourself!
