Module 1 — Inside the Machine (Hardware)

Meet the main parts of a computer — and learn how data moves through them.

1 — The Computer “Loop”

A computer is a system that repeatedly does this loop:

Input

Keyboard, mouse, mic, camera, touchscreen

Process

CPU + RAM work together to run instructions

Store

SSD/HDD keep files and programs long-term

Output

Screen, speakers, printer, network

Big idea: Coding becomes real only when it runs on hardware.

2 — CPU vs RAM vs Storage (Why All Three Matter)

CPU

Executes instructions (math + logic). Often has multiple cores. It is housed on the mother board which connects all major components together.

RAM

Fast “working space” for what’s running right now. Clears when power is off.

Storage

Holds programs + files long-term. Slower than RAM, but keeps data when off.

GPU

Specialized processor for graphics (games, video, AI workloads).

Memory vs Storage: RAM is fast + temporary. Storage is slower + permanent.

3 — Data Journey: “Open a Game”

When you open a game or app, data travels like this:

1. The app is stored on your SSD/HDD.
2. The OS loads needed parts into RAM.
3. The CPU reads instructions from RAM and runs them.
4. The GPU helps draw frames → sent to the screen.

Why it matters: A slow storage drive or low RAM can make loading feel “laggy.”

Module 2 — Bits, Bytes & Data

Zoom into the tiny pieces of information computers use to represent everything.

1 — Bit Basics

A bit is the smallest piece of information a computer uses. It can be:

  • 0 or 1
  • off or on
  • false or true

Big idea: Everything digital becomes patterns of 0s and 1s.

2 — Bytes & File Sizes (Two Ways of Counting)

Bits are grouped into bytes and larger units:

  • 8 bits = 1 byte
  • Decimal: 1 KB = 1,000 bytes (common in storage marketing)
  • Binary: 1 KiB = 1,024 bytes (common in computing)
  • 1 MB ≈ 1,000 KB (or 1 MiB = 1,024 KiB)

Don’t stress the names — just remember: bigger unit = more bytes.

Letters are stored as numbers (which become bits). For example, in ASCII/Unicode:

  • A is often represented as the number 65
  • a is often represented as 97

5 — Images: Pixels + Color Depth

Images are grids of tiny dots called pixels.

  • More pixels (higher resolution) usually = bigger file.
  • More colors (higher color depth) usually = bigger file.

Example: 1920×1080 has over 2 million pixels.

6 — Why Some Files Are Smaller (Compression)

Compression is a way to store data using fewer bytes.

  • Lossless (PNG, ZIP): tries to keep everything exact.
  • Lossy (JPG, MP3): throws away some detail to shrink more.

Big idea: File type + compression changes size a lot.

Module 3 — Files, Folders & Operating Systems

Learn how computers organize work — and how the OS keeps everything running.

1 — What Is an Operating System?

The operating system (OS) is the main program that:

  • Manages hardware (CPU, RAM, disk, devices)
  • Runs applications (games, browsers, editors)
  • Handles files and folders
  • Protects users with permissions and logins

Examples: Windows, macOS, Linux, Android, iOS.

2 — OS vs Apps (Who Does What?)

Apps are things you use (browser, game). The OS is what lets apps share the computer safely.

  • The OS decides which app gets CPU time.
  • The OS allocates RAM and cleans up when apps close.
  • The OS manages devices (keyboard, mic, camera) through drivers.

Big idea: Without an OS, apps don’t have a clean way to “talk” to hardware.

3 — Files, Folders, and Paths

A file is a named package of data. A folder (directory) holds files and other folders.

A path tells you where something is:

  • Documents/School/Essay.docx
  • Pictures/Vacation/photo.png

Tip: Clean paths make projects easier to back up.

4 — Extensions & File Types

The letters after the dot are the extension:

  • .docx = document
  • .png = image
  • .mp3 = audio
  • .html = web page

Big idea: Extensions help the OS choose which app should open a file.

5 — Permissions (Safety + Organization)

Permissions are rules about who can access what.

  • Read: view/open
  • Write: change/save
  • Execute: run a program

Why it matters: Permissions protect important files and user accounts.

Module 4 — Networks & the Internet

Learn how computers talk to each other across networks and the internet.

1 — Network vs Internet

A network is a group of connected computers that can share information.

  • Home Wi-Fi network (LAN)
  • School network
  • Internet = a global network of networks

2 — Packets + Routers

Data is usually split into small pieces called packets.

  • Packets can take different routes.
  • Routers help send packets to the next best step.

Big idea: The internet is like a huge delivery system for packets.

3 — IP Addresses & DNS

Computers use IP addresses (like numeric street addresses).

DNS is like the internet’s phonebook — it turns names into IP addresses.

  • example.com → DNS → IP address

4 — Client & Server (Request → Response)

Most websites use a client–server pattern:

  • Client: your device asking for a page
  • Server: the computer that stores the page and sends it back

HTTP/HTTPS: common “rules” for web requests and responses.

6 — Safe & Smart Internet Use

The internet is powerful, so we use it with care:

  • Keep personal details private unless you trust the site.
  • Use strong passwords and don’t share them.
  • Look for HTTPS on sites that handle logins/payments.
  • Ask for help if something online feels wrong or unsafe.
