Module 1 — Putting It Together: State & Flow

We’ll connect variables, logic, and loops into one idea: program state and control flow.

1 — Program State

State is the “current situation” of your program.

  • Variables hold the state: level, health, coins.
  • Every time something changes, the state changes.
  • State + logic decide what happens next.

2 — Control Flow

Control flow is the path your code takes as it runs.

  • Sequence: line 1, then 2, then 3…
  • Branches: if / else decide which block to run.
  • Loops: repeat a block while a condition is true.

Putting these together lets you describe real stories in code.

3 — Flow Diagrams in Words

We can describe flow in plain language first:

  • Start with steps = 0.
  • Every minute, add the steps you take.
  • If steps ≥ 10,000 → show “Goal reached!”

Later we turn this into actual code.

Module 2 — Smart Decisions: Else-If, AND / OR, Nested Logic

We’ll level up from simple if statements to more complex decision trees.

1 — Else-If Chains

Sometimes we need more than two choices.

if (temp > 30) {
  show("Very hot");
} else if (temp > 20) {
  show("Warm");
} else if (temp > 10) {
  show("Cool");
} else {
  show("Cold");
}

This is called an else-if chain.

2 — AND (&&) and OR (||)

  • AND (&&): both sides must be true.
  • OR (||): at least one side is true.
if (age >= 13 && age < 18) { ... }
if (weather === "rain" || weather === "snow") { ... }

3 — Nested Conditions

One if can live inside another. That’s called nesting.

if (loggedIn) {
  if (isAdmin) {
    showAdminPanel();
  } else {
    showUserHome();
  }
}

Nesting is powerful, but too much can make code hard to read.

Module 3 — Loop Patterns & Mini Tables

Here we use loops to build patterns, lists, and tiny data tables.

1 — Counting in Different Steps

Loops don’t have to count by 1.

for (let i = 0; i <= 20; i += 5) {
  // 0, 5, 10, 15, 20
}

This is useful for scores, levels, and time jumps.

2 — Looping Over Arrays

const colors = ["red", "green", "blue"];
for (let i = 0; i < colors.length; i++) {
  console.log(colors[i]);
}

We use array.length so the loop adapts to any size.

3 — Mini Tables

Loops are great for building tables of information like multiplication or schedules.

for (let i = 1; i <= 10; i++) {
  console.log("3 x " + i + " = " + (3*i));
}

Module 4 — Stronger Functions: Parameters, Return & Scope

We’ll use functions as tiny machines that take inputs and give back answers.

1 — Multiple Parameters

function mix(name, flavor) {
  return name + " chose " + flavor;
}
const msg = mix("Alex", "vanilla");

Functions can take more than one input value.

2 — Return vs. Console Output

  • return sends a value back to whoever called the function.
  • console.log just prints a message for humans to read.

Good functions usually return values so other code can use them.

3 — Scope (Where Variables Live)

Scope is the region of code where a variable can be seen.

  • Inside a function → local to that function.
  • Outside functions → often global to the file.

Module 5 — Arrays of Objects & Mini Project Planning

We’ll treat each thing (player, task, item) as an object and store many of them in an array.

1 — Objects as Bundles

An object groups related values under one name.

2 — Arrays of Objects

const players = [
  { name: "Sky", score: 120 },
  { name: "River", score: 95 },
  { name: "Nova", score: 140 }
];

We can loop over players just like any other array.
