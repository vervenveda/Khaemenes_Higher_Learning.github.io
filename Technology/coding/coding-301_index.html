Module 1 — Variables & Data Types (Real Code)

We’ll turn your Coding 101/201 ideas into actual JavaScript and Python syntax.

1 — From Pseudocode to Real Code

We can write an idea three ways:

  • Pseudocode: “Set score to 0. Add 10 when the player wins.”
  • JavaScript: let score = 0; score = score + 10;
  • Python: score = 0; score = score + 10

Variables are named boxes that store values while the program runs.

2 — Variables as Labeled Boxes

A variable is a labeled box in memory. We can update it as the game changes.

  • JavaScript: let lives = 3;
  • Python: lives = 3

We read from the box and write new values into it.

3 — Common Data Types

Variables can hold different types of data:

  • Number: 42, 3.14
  • String (text): "hello", "Jenny"
  • Boolean: true or false

JavaScript and Python both use these types, with slightly different syntax.

We choose one path or another using if and else.

secret = random.randint(1, 10)

    guess = int(guess_text)

    else:
        print("Too high! The secret was", secret)

Module 3 — Loops & Arrays

We’ll use loops and arrays/lists to build simple scoreboards and patterns.

1 — Arrays / Lists

An array (or list) holds several values in order:

// JavaScript
const scores = [8, 10, 6];
# Python
scores = [8, 10, 6]

We can loop through all scores to calculate totals and averages.

2 — For Loops

We can sum all the scores using a loop.

// JavaScript
let sum = 0;
for (let i = 0; i < scores.length; i++) {
  sum += scores[i];
}
# Python
total = 0
for s in scores:
    total += s

Module 4 — Functions & Reuse

Functions are reusable blocks of code that do specific jobs.

1 — What Are Functions?

A function is a named block of code we can call whenever we need that job done.

// JavaScript
function greet(name) {
  console.log("Hello " + name);
}
# Python
def greet(name):
    print("Hello " + name)

2 — Parameters & Return Values

Functions can take inputs (parameters) and give back an answer (return value).

// JavaScript
function add(a, b) {
  return a + b;
}
# Python
def add(a, b):
    return a + b

Python Dice Roller (reference)

import random

def roll_die(sides):
    return random.randint(1, sides)

def roll_many(times, sides):
    results = []
    for _ in range(times):
        results.append(roll_die(sides))
    return results

times = int(input("How many dice? "))
sides = int(input("How many sides per die? "))

rolls = roll_many(times, sides)
print("You rolled:", rolls)

Module 5 — Arrays & Debugging

We’ll practice working with lists of data and hunting down bugs.

1 — Lists & Arrays

Arrays (JS) and lists (Python) hold many values in one variable.

// JavaScript
const tasks = ["code", "draw", "read"];
# Python
tasks = ["code", "draw", "read"]

2 — Indexes & Access

We use indexes to access each item. In many languages, indexes start at 0.

  • tasks[0] → first item
  • tasks[1] → second item
  • tasks[2] → third item

3 — Debugging Toolkit

A bug is a mistake in code. Debugging is how we find and fix those mistakes.

  • Read error messages carefully.
  • Use the console or print statements to see values.
  • Change one thing at a time.
  • Explain the code out loud (“rubber duck debugging”).

habits = []

def add_habit(name, done):

        box = "✅ " if h["done"] else "⬜ "
