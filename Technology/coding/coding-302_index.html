Module 1 — Variables & Data Types (Level Up)

We’ll go a little deeper with variables and types, focusing on predicting what code will do before we run it.

1 — Quick Review: Updating Variables

Imagine this code:

let score = 10;
score += 5;
score -= 3;

Before you run it, try to predict the final value of score.

2 — Variables in JavaScript and Python

Same idea, different syntax:

// JavaScript
let coins = 3;
coins = coins * 2 + 1;
# Python
coins = 3
coins = coins * 2 + 1

Try to work out the final value of coins in your head.

3 — Types Still Matter

JavaScript and Python both have numbers, strings, and booleans:

  • Number: 7, 3.14
  • String: 'hello', '42'
  • Boolean: true / false in JS, True / False in Python

typeof in JavaScript tells you the type:

typeof 7;      // "number"
typeof '7';    // "string"

Module 2 — Logic & Conditions (Level Up)

Now we’ll combine conditions into more powerful rules and tiny game-like decisions.

1 — Combined Conditions

We can combine comparisons with && (“and”) and || (“or”).

let score = 12;
let lives = 1;

if (score >= 10 && lives > 0) {
  console.log('Level up');
} else {
  console.log('Game over');
}

Think about which branch will run before you execute it.

2 — Ranges and “Between” Logic

Checking if a number is between two values comes up all the time:

// JavaScript
if (age >= 13 && age <= 19) {
  console.log('Teen');
}
# Python
if age >= 13 and age <= 19:
    print('Teen')

3 — Else If Chains

Multiple branches let us choose exactly one message:

// JavaScript
if (score >= 50) {
  console.log('Legend');
} else if (score >= 20) {
  console.log('Powering up');
} else {
  console.log('Keep going');
}
# Python
if score >= 50:
    print('Legend')
elif score >= 20:
    print('Powering up')
else:
    print('Keep going')

Module 4 — Functions & Reuse (Level Up)

Functions become even more powerful when we use them to organise repeated logic.

1 — Functions as Building Blocks

A function wraps a job into a reusable piece:

// JavaScript
function triple(x) {
  return x * 3;
}
# Python
def triple(x):
    return x * 3

2 — Parameters & Return Values

Inputs are called parameters, and return sends a value back.

// JavaScript
function add(a, b) {
  return a + b;
}
# Python
def add(a, b):
    return a + b

5 — Dice Statistics Sandbox

This sandbox rolls some dice and counts how often each face appears.

JavaScript Dice Stats

(console.log output will appear here)

Python Dice Stats (reference)

import random

def roll_die(sides):
    return random.randint(1, sides)

def roll_many(times, sides):
    results = []
    for _ in range(times):
        results.append(roll_die(sides))
    return results

def count_faces(results, sides):
    counts = [0] * sides
    for face in results:
        counts[face - 1] += 1
    return counts

times = 5
sides = 6
rolls = roll_many(times, sides)
print("You rolled:", rolls)
counts = count_faces(rolls, sides)
print("Counts per face:", counts)

Module 5 — Arrays & Debugging (Level Up)

Finally, we’ll lean on arrays/lists and practice spotting bugs using real error clues.

1 — Lists & Arrays

Arrays (JS) and lists (Python) hold many values in one variable:

// JavaScript
const tasks = ['code', 'draw', 'read'];
# Python
tasks = ['code', 'draw', 'read']

2 — Indexes & Access

Most languages start indexes at 0:

  • tasks[0] → first item
  • tasks[1] → second item
  • tasks[2] → third item

Off-by-one mistakes (looping too far) are a very common bug.

3 — Debugging Toolkit

A bug is a mistake in code. Debugging is how we find and fix those mistakes.

  • Read error messages carefully.
  • Use the console or print statements to see values.
  • Change one thing at a time.
  • Explain the code out loud (“rubber duck debugging”).
