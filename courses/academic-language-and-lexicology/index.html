About the Vocabulary Engine

Courses supply reviewed terms and context. The shared engine handles study, written investigation, randomized objective checkpoints, 80% mastery, retries, and portable progress without changing the owning course curriculum.

Course Features

Curriculum-Fed Terms

Each course keeps its own vocabulary data while the engine provides one consistent study experience.

80% Mastery

Objective checkpoints require at least 80% before the next vocabulary unit unlocks.

Context & Investigation

Definitions are paired with disciplinary context and evidence-based written prompts.

Portable Progress

Progress remains local-first and can be exported or imported as JSON using the existing vocabulary record format.

Vocabulary Workspace

Search, study, investigate, and complete the current unit checkpoint.

How This Course Works

Each unit combines contextual examples, analysis of word structure and meanings, an original writing task, and a randomized objective checkpoint. Practice is formative. A score of at least 80% on the four-question unit checkpoint is required to unlock the next unit.

Complete the written investigations and save evidence for teacher review; the automatic score assesses only the objective questions.
