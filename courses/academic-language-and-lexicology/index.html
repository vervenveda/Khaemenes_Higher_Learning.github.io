How this course works

Each unit combines contextual examples, analysis of word structure and meanings, an original writing task, and a randomized objective checkpoint. Practice is formative. A score of at least 80% on the four-question unit checkpoint is required to unlock the next unit.

Complete the written investigations and save evidence for teacher review; the automatic score assesses only the objective questions. The current foundation has four introductory modules. Expansion into a full collegiate syllabus, supervised writing rubrics, and multi-grade packages will follow.

Works as a static HTML file after the word-bank data loads. Progress uses browser-local storage and can be exported; no account or external assessment service is required. Other-language translations should be introduced only after review.
