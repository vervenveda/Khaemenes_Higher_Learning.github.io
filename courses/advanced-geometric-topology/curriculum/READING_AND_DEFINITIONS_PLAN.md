# Reading & Definitions Plan

This file is intentionally a planning scaffold.

We will add actual readings only after auditing the existing 180 sessions and determining what each week genuinely requires.

For each week eventually record:

- Required definitions
- Required theorem statements
- Recommended worked examples
- Required reading
- Optional enrichment
- Historical/contextual reading
- Research-level reading
- Vocabulary review
- Theorem dependency notes

Do not add external readings merely to make the course look fuller. Every reading should serve a defined curriculum objective.
