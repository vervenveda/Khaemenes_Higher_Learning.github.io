Quotient Spaces & Polygonal Schemas

1. Core Definitions

Equivalence relation
A relation ~ on X that is reflexive, symmetric, and transitive.
Equivalence class [x]
The set {y in X : y ~ x}.
Quotient set X/~
The set whose elements are the equivalence classes of ~.
Quotient map q
The natural surjection q:X→X/~ defined by q(x)=[x].
Quotient topology
U⊆X/~ is open exactly when q⁻¹(U) is open in X.
Surface / 2-manifold
For this course, a Hausdorff, second-countable space locally homeomorphic to R².
Polygonal presentation
A polygonal region together with boundary-edge pairing and orientation data used to specify a quotient.
Homeomorphism
A continuous bijection with continuous inverse.

2. The Quotient Construction at a Glance

  1. Begin with a topological space X.
  2. Specify an equivalence relation ~.
  3. Replace each point x by its class [x].
  4. Form X/~, the set of equivalence classes.
  5. Use q:X→X/~ to define the quotient topology.

Diagnostic question: When someone says “glue these points,” ask: what equivalence relation is being generated?

4. Boundary-Word Convention

Choose a direction for traversing the polygon boundary and a direction for each labeled edge. Record a label with exponent +1 when its chosen edge direction agrees with the boundary traversal and exponent −1 when it opposes the traversal.

A standard torus presentation can be written:

a b a−1 b−1

Convention warning: Authors may draw arrows or encode words differently. Interpret the stated identification rule before comparing formulas.

5. Vertex-Equivalence Algorithm

  1. Name every corner of the polygon.
  2. Take one paired edge at a time.
  3. Use the edge directions to determine which endpoints correspond.
  4. Write those endpoint relations explicitly.
  5. Combine all relations using transitivity.
  6. The resulting equivalence classes are the quotient vertices of this cell structure.

Rule: Never use the raw number of polygon corners as V unless you have proved that they remain distinct after identification.

6. Cell Counts and Euler Characteristic

For the finite cell structures used in this unit:

χ = V − E + F

  • V: number of vertex equivalence classes;
  • E: number of edge equivalence classes;
  • F: number of 2-cells.

For the standard one-square torus presentation: V=1, E=2, F=1, hence χ=0.

8. Surface Check

An arbitrary quotient of a polygon is not automatically a surface. For a quotient to be a 2-manifold, every quotient point must have the required local Euclidean neighborhood. Suspicious points usually occur at identified boundary vertices or unusual collapsed boundary sets.

Diagnostic: Inspect the equivalence classes first; then inspect neighborhoods of the quotient points created from them.

10. Diagnostic Examples

A. Equivalence relation

On R, x~y when x−y∈Z. This is reflexive, symmetric, and transitive, so the quotient R/~ is defined.

B. Torus cell count

In the standard square presentation, all four corners are identified, the four sides form two edge classes, and the interior is one face. Thus (V,E,F)=(1,2,1).

C. Nonexample warning

If an identification creates a quotient point whose neighborhood branches or otherwise fails to look locally like an open disk, the quotient is not a surface at that point.

11. Fast Audit Before Naming a Quotient

  1. What is the underlying polygonal region?
  2. Which edges are paired?
  3. What are the pairing directions?
  4. Which endpoints become equivalent?
  5. What are the final vertex classes?
  6. How many edge classes and faces remain?
  7. What is χ?
  8. Is there evidence of orientation reversal?
  9. Does every quotient point satisfy the local surface condition?
  10. Which conclusion is proved, and which is only suggested by the diagram?

13. Self-Test

  1. Define quotient topology without using the word “glue.”
  2. Why is the quotient map naturally surjective?
  3. What two pieces of information must an edge-identification diagram communicate?
  4. Describe the algorithm for finding quotient vertices.
  5. Why is χ=V−E+F not computed from the unprocessed polygon counts?
  6. State the difference between edge orientation and orientability.
  7. What local condition must be checked before calling an arbitrary quotient a surface?
  8. Why can a surface have more than one polygonal presentation?

14. Accessibility & Reading Conventions

Edge pairings must be communicated by text labels in addition to arrows or color. A diagram description should state the boundary order, edge labels, directions, and endpoint correspondences. Read “X/~” as “X modulo the equivalence relation” and “χ=V−E+F” as “Euler characteristic equals vertices minus edges plus faces.”
