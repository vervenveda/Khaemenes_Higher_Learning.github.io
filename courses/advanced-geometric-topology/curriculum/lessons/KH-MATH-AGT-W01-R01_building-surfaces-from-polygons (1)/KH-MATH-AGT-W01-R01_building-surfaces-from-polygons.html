Building Surfaces from Polygons

Advanced Geometric Topology · Unit 1 · Week 1 · Session 1

Khaemenes Scholarly Resource: KH-MATH-AGT-W01-R01

1. Why Topologists Build Spaces by Gluing

Imagine a square made from perfectly flexible mathematical material. Mark the left and right edges with the same letter, and mark the top and bottom edges with another letter. Now declare that corresponding points on each matching pair are to represent the same point.

This is more than bending paper. We have specified which points are to be regarded as identical. The new object is a quotient space. Polygon models are powerful because they convert a global topological object into finite combinatorial instructions: a polygon, paired boundary edges, and rules describing how those edges are identified.

Throughout this course, a picture is a guide to reasoning—not a replacement for it.

2. Prerequisite: Equivalence Relations

An equivalence relation on a set X is a relation ~ satisfying three conditions for all x, y, z in X:

  1. Reflexive: x ~ x.
  2. Symmetric: if x ~ y, then y ~ x.
  3. Transitive: if x ~ y and y ~ z, then x ~ z.

The equivalence class of x is [x] = {y in X : y ~ x}. The quotient set X/~ is the set of all equivalence classes.

Example. On the real line, declare x ~ y when x − y is an integer. Then numbers differing by an integer belong to the same class. The quotient identifies the repeating copies of a unit interval in a way closely related to a circle.

3. Quotient Spaces

Suppose X is a topological space with an equivalence relation ~. Let q : X → X/~ send each point x to its equivalence class [x]. We give X/~ the quotient topology: a subset U of X/~ is open exactly when q−1(U) is open in X.

This definition matters because “identify these points” is not merely a drawing instruction. It specifies a new set of points—equivalence classes—and a topology on that set.

The map q is called the quotient map. In our polygon constructions, X will usually be a polygonal region and the equivalence relation will identify selected points on its boundary.

4. From a Polygon to a Surface

Let P be a polygonal region. Pair its boundary edges. For each pair, specify which points correspond. The resulting identifications generate an equivalence relation on P. Interior points normally remain in singleton classes, while boundary points may be identified with points on paired edges.

The quotient P/~ is the object we study.

When the identifications satisfy the appropriate conditions, the quotient is a surface: every point has a neighborhood homeomorphic to an open subset of the plane. Later we will examine why this local condition is essential.

Critical distinction: P is a presentation. P/~ is the quotient space. Do not silently treat them as the same object.

5. Reading Edge-Identification Diagrams

An edge-identification diagram contains two kinds of information:

  • pairing: which edges are to be identified;
  • direction: how corresponding points on those edges match.

Repeated labels tell us which edges belong together. Arrows or exponents encode direction. The direction is mathematically significant: changing it can change the homeomorphism type of the quotient.

When reading a diagram, first identify the edge pairs. Only then determine which endpoints become equivalent.

6. Edge Words

A polygonal presentation can be encoded by walking once around the boundary and recording the labeled oriented edges. One common convention writes an edge with exponent +1 when its chosen arrow agrees with the boundary traversal and exponent −1 when it opposes that traversal.

For example, a standard torus presentation is often represented schematically by a word of the form

a b a−1 b−1.

The exact appearance of a diagram depends on convention, so never memorize an isolated picture without also understanding the identification rule it encodes.

7. Standard Construction: The Torus

Begin with a square. Identify one pair of opposite edges in the corresponding direction. The intermediate quotient may be visualized as a cylinder. Then identify the two remaining boundary circles according to the second edge pairing. The resulting quotient is homeomorphic to a torus.

The familiar “bend the cylinder into a doughnut” picture is useful intuition, but the mathematical object is determined by the quotient identifications. It does not depend on whether we can realize every stage without stretching through three-dimensional space.

Vertex audit

Track the four corners through both edge identifications. In the standard torus presentation all four polygon vertices belong to a single vertex equivalence class. The two edge pairs give two edge classes, and the polygon interior supplies one 2-cell. Thus this cell structure has V = 1, E = 2, F = 1.

We will soon use these values to compute an invariant.

8. Other Benchmark Surfaces

Sphere

A sphere admits polygonal presentations in which paired boundary arcs collapse the boundary data into a quotient homeomorphic to S². Different polygonal presentations may describe the same sphere; the presentation is not unique.

Real projective plane

The real projective plane can be obtained by identifying boundary data so that antipodal directions are identified. A polygon model records this using an orientation-reversing pattern. This is one of our first important nonorientable examples.

Klein bottle

A Klein-bottle presentation can be obtained from a square by pairing one direction in the ordinary way and the other with a twist in the identification. Like the projective plane, the Klein bottle is nonorientable.

These descriptions are previews. In the proof workshop and laboratory you will track the identifications explicitly rather than relying on the names of familiar pictures.

9. Vertex Equivalence Classes

Edge identifications also identify endpoints. To find the vertices of the quotient cell structure, do not simply count the corners of the original polygon.

  1. Label every polygon vertex.
  2. For each paired edge, determine which endpoint corresponds to which endpoint.
  3. Record the resulting vertex relations.
  4. Take the transitive closure of those relations.
  5. Count the resulting equivalence classes.

This is one of the most important technical habits in the unit.

10. Faces, Edges, Vertices, and Euler Characteristic

For a cell decomposition with finitely many cells, the Euler characteristic is

χ = V − E + F.

For the standard one-square torus presentation discussed above, V = 1, E = 2, and F = 1, so χ = 0.

The arithmetic is elementary. The topology lies in determining the correct equivalence classes before doing the arithmetic.

In Week 3 we will study Euler characteristic as an invariant much more carefully. For now, regard it as a powerful clue extracted from the quotient's cell structure.

11. First Intuition for Orientability

Very roughly, an orientable surface permits a consistent choice of local orientation as one moves around the surface. A torus and sphere are orientable; the projective plane and Klein bottle are not.

Edge arrows help diagnose how local orientations interact under gluing, but do not confuse an arrow on a polygon edge with orientability itself. Orientability is a global property of the resulting surface.

A rigorous treatment comes later. At this stage, your task is to notice when an identification reverses local orientation and to ask what happens when that reversal is carried around the quotient.

12. Polygon Versus Quotient

This distinction deserves repetition:

  • The polygon is a convenient domain carrying gluing instructions.
  • The quotient point [x] may contain several polygon points.
  • Raw polygon corners need not remain distinct quotient vertices.
  • Different polygons or edge words may yield homeomorphic quotient surfaces.

Classification therefore cannot mean “classify the drawings.” It means classify the resulting surfaces up to homeomorphism.

13. Examples and Nonexamples

Example: A square with opposite sides paired appropriately gives a standard torus quotient.

Example: A square with a twisted identification in one direction can present a Klein bottle.

Nonexample warning: Arbitrarily collapsing boundary pieces or identifying edges without checking local neighborhoods need not produce a surface. A quotient can contain a singular point whose neighborhood is not homeomorphic to an open disk.

This is why “there is a gluing diagram” is not enough to conclude “the quotient is a surface.”

14. Worked Identification Audit

Suppose a square has two pairs of edges labeled a and b. Before naming the quotient:

  1. Write the boundary word using the chosen orientation convention.
  2. Record which endpoints are matched by the a-pair.
  3. Record which endpoints are matched by the b-pair.
  4. Combine these relations into vertex equivalence classes.
  5. Count the edge classes.
  6. Count the 2-cells.
  7. Compute χ.
  8. Inspect whether either gluing reverses the local orientation convention.
  9. Only then compare the evidence with known surface models.

This procedure is deliberately slower than guessing from the picture. It is also much more reliable.

15. Common Errors

  1. Counting raw corners. Correct method: count vertex equivalence classes after all identifications.
  2. Ignoring arrows. Correct method: pairing and direction are both part of the data.
  3. Naming from appearance. Correct method: audit the quotient construction.
  4. Treating visualization as proof. Correct method: use visualization to form or check a conjecture, then justify the topological claim.
  5. Assuming uniqueness. Correct method: remember that one surface can have many polygonal presentations.
  6. Confusing edge orientation with surface orientability. Correct method: analyze the global consistency induced by all identifications.

16. Check Your Understanding

  1. State the three properties of an equivalence relation.
  2. What are the points of X/~?
  3. Define the quotient topology using the quotient map q.
  4. Explain why a polygonal presentation contains more information than a list of paired edge labels.
  5. Why should the corners of the original polygon not automatically be counted as distinct vertices?
  6. For the standard one-square torus cell structure, compute χ.
  7. Explain the difference between an edge arrow and orientability.
  8. Why can two different polygon diagrams represent the same topological surface?
  9. Give one reason a quotient obtained by arbitrary identifications might fail to be a surface.
  10. Explain in your own words why physically folding a paper model is evidence for intuition but not, by itself, a proof of homeomorphism.

17. Mastery Gate for This Reading

Before moving into the proof workshop, you should be able to:

  • define equivalence relation, equivalence class, quotient set, quotient map, and quotient topology;
  • read paired-edge information from a polygonal schema;
  • track induced vertex identifications;
  • distinguish a polygonal presentation from its quotient;
  • explain the standard torus construction without relying only on a picture;
  • compute V, E, F and χ for the standard one-square torus cell structure;
  • state clearly what remains unproved when a conclusion is based only on visualization.

18. Looking Ahead

Session 2 turns these constructions into proof work. Session 3 develops a systematic polygon-gluing laboratory. Week 2 asks the larger question: if compact connected surfaces can be represented by polygonal data, can all such surfaces be classified?

The classification theorem will eventually tell us that surprisingly little information is needed to distinguish closed connected surfaces up to homeomorphism. We are not entitled to use that theorem yet. First we build the machinery that makes the theorem meaningful.

19. Vocabulary & Notation

~
An equivalence relation.
[x]
The equivalence class of x.
X/~
The quotient set, equipped here with the quotient topology.
q
The quotient map x ↦ [x].
Polygonal presentation
A polygonal region together with paired, oriented boundary-identification data representing a quotient space.
Homeomorphic
Topologically equivalent via a continuous bijection with continuous inverse.
χ
Euler characteristic, V − E + F for the finite cell decompositions considered here.

20. Accessibility Notes

No mathematical conclusion in this reading requires color. Edge pairs should always be distinguished by labels as well as arrows. Any future diagram accompanying this reading should include a textual description stating the boundary traversal, paired labels, arrow directions, and endpoint correspondences.

Expressions such as X/~ and χ = V − E + F should be accompanied in accessible renderings by spoken-text equivalents: “X modulo the equivalence relation” and “Euler characteristic equals vertices minus edges plus faces.”
