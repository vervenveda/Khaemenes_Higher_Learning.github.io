Simplicial Approximation Laboratory

Advanced Geometric Topology · Self-Paced Lesson 13

Resource ID: KH-MATH-AGT-L13-LAB02

Arc 02: Triangulations & Combinatorial Surfaces

Mode: inspect → subdivide → choose vertices → verify → compare → justify

Laboratory Question

How can a continuous map between triangulated spaces be replaced, after suitable subdivision, by a simplicial map that preserves the homotopy information we care about?

continuous map → finer triangulation → simplicial approximation → homotopy comparison

Learning Targets

  • Recognize when a given continuous map is not simplicial for the current triangulation.
  • Use barycentric subdivision to create a finer source complex.
  • Apply a practical star-based simplicial-approximation criterion.
  • Construct a simplicial map from a vertex assignment.
  • Verify that every source simplex maps to a target simplex.
  • Distinguish exact equality of maps from homotopy.
  • Record experimental/combinatorial evidence separately from theorem-based conclusions.
  • Produce a reproducible map-audit record.

1. Laboratory Setup

Let K and L be finite simplicial complexes and let F:|K|→|L| be continuous. A simplicial approximation g:K→L is not chosen arbitrarily. Its vertex images must reflect where F sends sufficiently small neighborhoods around the source vertices.

One standard criterion is:

F(stK(v)) ⊆ stL(g(v))

for every vertex v of K, where st denotes the open star. When the current triangulation is too coarse to satisfy such choices, subdividing K can make the stars smaller.

Scope: this laboratory uses the star criterion as an operational tool. A full proof of the simplicial approximation theorem is deferred.

Investigation A — A Map Already Simplicial

Let K be the triangular circle with vertices a,b,c and edges ab,bc,ca. Let L be the triangular circle with vertices x,y,z and edges xy,yz,zx.

Define F on vertices by a↦x, b↦y, c↦z and extend linearly on each edge.

  1. Verify directly that the vertex rule is simplicial.
  2. Describe |F| on each source edge.
  3. Explain why no subdivision is needed.
  4. Determine whether this map is a simplicial isomorphism.

Investigation B — A Valid Collapse

Use the same source and target circles, but define a↦x, b↦x, c↦y.

  1. Audit the images of ab,bc,ca.
  2. Determine whether the vertex rule is simplicial.
  3. Identify which simplex collapses in dimension.
  4. Explain why simpliciality does not imply homeomorphism.
  5. Describe the induced map qualitatively.

Investigation C — A Coarse Triangulation That Fails

Let K be a single edge ab and let L be a path with vertices x-y-z. Consider a continuous map F:[a,b]→|L| whose image runs from x through y to z.

A vertex rule using only a and b cannot map the source edge to the two-edge path x-y-z because the image of one source simplex must be a single simplex of L.

  1. Explain why the coarse source triangulation cannot encode this map simplicially.
  2. Subdivide ab by inserting m.
  3. Define a↦x, m↦y, b↦z.
  4. Verify that am maps to xy and mb maps to yz.
  5. Explain how subdivision made the simplicial description possible.

Reasoning lesson: subdivision creates combinatorial resolution.

Investigation D — Star Criterion on a Subdivided Interval

Continue with the subdivided interval a-m-b and the target path x-y-z.

  1. List the open star of each source vertex.
  2. Describe where F sends those stars.
  3. For each source vertex v, check whether F(st(v)) lies in the open star of the proposed image vertex g(v).
  4. Record whether the star criterion is satisfied.

This investigation separates two tasks: verifying that g is simplicial and verifying that g is compatible with the continuous map F in the sense required for simplicial approximation.

Investigation E — One Barycentric Subdivision

Take a single triangle abc. Form its barycentric subdivision sd K.

  1. List the seven subdivision vertices by the faces of K they represent.
  2. List the six small triangular facets as chains vertex⊂edge⊂triangle.
  3. Choose a target triangle xyz.
  4. Design a vertex assignment from sd K to xyz that is simplicial.
  5. Audit all six small triangles.
  6. Record any collapsed triangles or edges.

Investigation F — Equality vs. Homotopy

Suppose g:sdnK→L is obtained from the simplicial approximation theorem for a continuous map F:|K|→|L|.

  1. Write the correct conclusion using the homotopy symbol ≃.
  2. Explain why F and |g| need not agree point-by-point.
  3. Give one reason algebraic topology may still permit replacing F by |g|.
  4. State one type of claim that would require more than homotopy equivalence of maps.

Investigation G — Diagnose a Bad Approximation Claim

“I chose the nearest target vertex for every source vertex. Therefore my vertex map is automatically a simplicial approximation.”

Identify at least three possible failures in this argument. Your analysis should address:

  • simplex compatibility;
  • the star criterion;
  • dependence on the triangulation;
  • the difference between visual closeness and a theorem hypothesis.

Investigation H — Build a Map That Needs Refinement

Create your own finite source complex K, target complex L, and continuous-map description F such that the current triangulation is too coarse for your intended simplicial encoding.

  1. Explain precisely why the original triangulation fails.
  2. Perform one valid subdivision.
  3. Give a new vertex assignment.
  4. Audit all source facets.
  5. State whether the new map is merely simplicial or is also supported as a simplicial approximation to F.

Investigation I — Counterexample Laboratory

Test each proposed rule:

  1. “Every continuous map between realizations is simplicial for the original triangulations.”
  2. “If a vertex map is simplicial, then it is a homeomorphism.”
  3. “If two maps are homotopic, then they are equal.”
  4. “Subdivision changes the homotopy type of the source.”
  5. “A visually close vertex assignment is automatically a simplicial approximation.”

For each statement, prove it from established results or supply a counterexample/reason it fails.

Investigation J — Reproducibility Exchange

Give your Investigation H record to another learner, or set it aside and return later. Using only the written record, reconstruct:

  • the source and target complexes;
  • the subdivision;
  • the proposed vertex map;
  • the facet audit;
  • the approximation conclusion.

Revise any ambiguous notation until the construction is reproducible.

Final Laboratory Report

Your final submission should contain:

  • completed audits for Investigations A–E;
  • a precise equality-vs.-homotopy analysis for F;
  • the repaired argument from G;
  • your original refinement problem from H;
  • counterexamples or proofs for I;
  • the reproducibility revision from J;
  • a conclusion answering the laboratory question;
  • a separate section titled What I verified directly and what I concluded by theorem.
