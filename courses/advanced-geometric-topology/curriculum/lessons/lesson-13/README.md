# Lesson 13 — Simplicial Approximation Laboratory

**Resource:** `KH-MATH-AGT-L13-LAB02`  
**Arc:** 02 — Triangulations & Combinatorial Surfaces  
**Delivery:** Self-Paced Laboratory

Integrates subdivision and simplicial maps through ten investigations. Learners decide when refinement is necessary, apply the open-star criterion, verify simplicial maps, distinguish exact equality from homotopy, diagnose bad approximation claims, construct original examples, and preserve reproducible map records.

The hardened version is fully printable and dependency-free.
