## Role in Week 1

- R01 teaches.
- CR01 provides the reusable reference.
- WE01 models complete reasoning.
- **PW01 transfers responsibility for the argument to the learner.**

The workshop uses graduated scaffolding. Early tasks contain hints and model arguments; later tasks deliberately remove those supports.

## Major proof competencies

1. endpoint-identification proofs;
2. quotient cell-count justification;
3. counterexample arguments;
4. local-Euclidean proof architecture;
5. proof-gap detection;
6. overclaim repair;
7. independent projective-plane argument;
8. formal proof audit and revision.
