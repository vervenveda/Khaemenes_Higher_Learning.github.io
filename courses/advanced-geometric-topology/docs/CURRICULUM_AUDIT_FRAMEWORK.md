# Curriculum Audit Framework

## Scope

This audit evaluates only the curriculum:

- academic level
- sequence
- prerequisites
- concepts
- definitions
- theorems
- proofs
- examples
- counterexamples
- exercises
- laboratories
- readings
- assessments
- research preparation
- synthesis

It intentionally excludes ecosystem architecture, external integrations, deployment, plugins, storage, and unrelated application engineering.

## Questions for every unit

### 1. Purpose
Why does this unit exist in the course?

### 2. Prerequisites
What must the learner already understand?

### 3. New mathematics
What genuinely new mathematical ideas are introduced?

### 4. Depth
Is the material:
- exposure
- conceptual understanding
- working competence
- proof-level mastery
- research preparation?

### 5. Mathematical actions
What does the learner actually do?

- define
- explain
- construct
- compute
- prove
- disprove
- classify
- visualize
- model
- interpret
- compare
- generalize
- apply
- reproduce
- critique
- synthesize
- defend

### 6. Evidence
What work demonstrates that learning occurred?

### 7. Transition
How does this unit prepare the learner for the next one?

## Red flags

- Topic dumping
- abrupt prerequisite jumps
- repetition without increasing difficulty
- computation without mathematical interpretation
- visualization presented as proof
- applications introduced without sufficient mathematical foundation
- assessments that do not measure stated objectives
- definitions used before being taught
- proofs requested without proof scaffolding
- advanced terminology introduced all at once
