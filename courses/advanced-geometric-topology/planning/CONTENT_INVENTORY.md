# Curriculum Content Inventory

Use this as the checklist for the eventual 180-session audit.

## Every session should be checked for

- [ ] Clear learning target
- [ ] Prerequisite identified
- [ ] New concept identified
- [ ] Precise definitions
- [ ] Example
- [ ] Counterexample or misconception check where appropriate
- [ ] Mathematical action
- [ ] Guided practice
- [ ] Independent practice
- [ ] Proof work where appropriate
- [ ] Computation/construction where appropriate
- [ ] Interpretation
- [ ] Reading/resource
- [ ] Reflection
- [ ] Evidence of learning
- [ ] Connection to previous mathematics
- [ ] Preparation for next mathematics

## Course-wide checks

- [ ] 36 weeks accounted for
- [ ] 180 sessions accounted for
- [ ] Every session has a unique identity
- [ ] Unit transitions are explicit
- [ ] Prerequisites are sufficient
- [ ] Proof difficulty increases
- [ ] Problem difficulty increases
- [ ] Counterexamples appear throughout
- [ ] Computation supports mathematics rather than replacing it
- [ ] Assessments align to learning objectives
- [ ] Research preparation is cumulative
