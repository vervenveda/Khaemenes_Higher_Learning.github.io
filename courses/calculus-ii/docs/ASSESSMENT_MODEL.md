# Assessment Model

- 40-question readiness diagnostic
- 13 randomized mastery checks
- 13 applied investigations
- 184-question original bank
- 60-question midterm
- 100-question comprehensive final
- corrected-work portfolio
- Unit 13 capstone and oral defense

Recommended weighting: coursework 25%, mastery 20%, investigations 20%, midterm 10%, final 15%, capstone 10%.
