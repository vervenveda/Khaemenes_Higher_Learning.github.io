# Academic Integrity and AI Use

Learners may use approved tools for brainstorming, visualization, checking algebra, comparing solvers, or testing parameter scenarios when use is disclosed. Final work must be understood, rewritten in the learner's own mathematical language, and independently verified. Undisclosed generated work, copied derivations, fabricated data, or software output without model specification and interpretation does not count as mastery. Formal assessments follow the evaluator's stated tool rules.
