# Faculty Implementation Guide

Use five sessions per week: concept/model seminar, analytical solution methods, interactive slope-field or numerical practice, physics/engineering application, and mastery/reflection. Begin with the readiness diagnostic and select a pathway. Foundation provides more scaffolding toward the same outcomes. Require equation classification, variables, conditions, units, method justification, interpretation, and at least one independent check in every substantial solution. Use oral questions periodically to confirm authorship and deepen mathematical communication.
