# Academic Integrity and AI Use

Approved tools may support brainstorming, code experiments, truth tables, graph layouts, test generation, or editing when use is disclosed. Final work must be understood, rewritten in the learner’s own mathematical language, and independently verified. Generated proofs, code, citations, or examples that the learner cannot defend do not count as mastery. Passing tests is not a universal proof unless a complete finite exhaustion is justified.
