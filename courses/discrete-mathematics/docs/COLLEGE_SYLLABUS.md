# Khaemenes Higher Learning Discrete Mathematics

**Course code:** KH-HL-MATH-DM1  
**Length:** 36 weeks · 180 sessions  
**Prerequisite:** Algebra fluency; programming experience helpful but not required. Calculus is not required.  
**Author:** Jennifer Pearl

## Course description

A rigorous first college course in discrete mathematics for computer science. The course develops formal logic, set and relation models, proof, induction, recursion, number theory, combinatorics, recurrences, discrete probability, graph theory, trees, Boolean systems, automata, asymptotic analysis, computability foundations, coding, security, and a substantial computing capstone.

## Learning architecture

Each lesson includes concept development, worked reasoning, Foundation/Core/Honors pathways, four interactive questions, a six-problem printable worksheet, reflection, and a matching faculty key. Every unit includes an investigation, pathway sets, and mastery check.

## Grading guidance

- Lessons and practice: 20%
- Unit mastery checks: 20%
- Investigations and portfolio: 20%
- Midterm: 15%
- Final: 15%
- Capstone and oral defense: 10%

## Technology and integrity

Technology may generate finite examples, truth tables, graph traversals, simulations, or checks. Learners must still define objects, justify the method, prove correctness where required, analyze edge cases and complexity, disclose tool use, and independently verify conclusions. A program passing tests is not by itself a proof for all inputs.
