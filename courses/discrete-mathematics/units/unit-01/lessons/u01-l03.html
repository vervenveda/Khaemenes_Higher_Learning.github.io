Core structure

2^n rows for n variables

Evaluating compound statements systematically across all truth assignments. Attend to exact definitions, quantifier order, domain, construction, proof obligations, counting overlap, graph assumptions, algorithm invariants, and complexity where relevant.

Vocabulary: proposition, truth value, negation, conjunction, disjunction, implication, biconditional, predicate, quantifier, validity.

Example 1

Evaluate (p→q)∧p for p=true and q=false.

p→q is false and p is true, so the conjunction is false.
