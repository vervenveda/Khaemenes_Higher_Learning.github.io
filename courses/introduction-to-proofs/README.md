# Khaemenes Higher Learning Introduction to Proofs

A rigorous transition from calculation to theorem-level reasoning: definitions, logic, quantifiers, sets, direct and indirect proof, induction, invariants, number theory, analysis proofs, mathematical writing, peer review, and an independent theorem defense.

- 36 weeks · 180 sessions
- 13 units · 92 lessons · 92 faculty keys
- 13 investigations · 13 mastery checks
- 40-question diagnostic · 60-question midterm · 100-question final
- Three pathways and three interactive laboratories

**Curriculum author:** Jennifer Pearl
