Proof by Contraposition

Proving an implication through the logically equivalent contrapositive. This lesson develops proof fluency, not merely symbolic manipulation. Examples guide conjecture formation; only a valid argument establishes the theorem.

Worked reasoning

Follow every definition, estimate, and inference.

Example 1

Prove: if n² is even, then n is even.

Prove the contrapositive: if n is odd, n=2k+1 and n² is odd.

Example 2 · Proof critique

Identify the first invalid step in a plausible but incomplete argument about Proof by Contraposition.
