# Khaemenes Higher Learning Linear Algebra

A complete 36-week college linear algebra course in matrix theory, vector spaces, and linear transformations.

## Course scale

- 36 weeks · 180 sessions
- 13 units · 92 lessons · 92 faculty keys
- 13 investigations · 13 mastery checks
- 40-question diagnostic · 60-question midterm · 100-question final
- Three placement-based pathways
- Three interactive laboratories
- Local-first records, print materials, and offline support

**Curriculum author:** Jennifer Pearl
