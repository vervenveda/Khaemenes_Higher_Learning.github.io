Matrix Factorization & Algorithm Design Studio

Use linear algebra to investigate scientific computing, repeated simulation, numerical software, and large structured systems. Submit an auditable mathematical memorandum and a short oral defense.

Phase 1 · Frame the system

  1. State a precise question and intended audience.
  2. Define every vector, matrix, space, transformation, variable, dimension, and unit.
  3. Document data sources or create a justified synthetic dataset.
  4. State assumptions, exclusions, and ethical or practical limitations.

Phase 2 · Build the mathematics

  1. Construct the matrix/vector model.
  2. Choose a method from this unit and justify the choice.
  3. Show one exact or symbolic derivation.
  4. Perform one computational or numerical implementation.

Phase 3 · Verify

  1. Check dimensions and hypotheses.
  2. Report residual, reconstruction, rank, determinant, orthogonality, or spectral evidence.
  3. Compare with an independent calculation or alternative method.
  4. Test sensitivity to at least one assumption or parameter.

Phase 4 · Communicate

  1. Write a 2–4 page memorandum with labelled figures/tables.
  2. Include limitations and responsible-use considerations.
  3. Prepare a 4–6 minute oral defense.
  4. Answer one challenge about method and one about interpretation.
