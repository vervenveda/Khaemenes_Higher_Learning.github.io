# Accessibility and Privacy

- Keyboard-accessible navigation and visible focus treatment
- responsive layouts for desktop, tablet, and mobile
- semantic headings, labels, fieldsets, legends, and live regions
- descriptive SVG titles and descriptions
- dark and light themes
- high-contrast print output
- local-first learner records with deliberate JSON/CSV/print export
- no analytics, advertising, account requirement, or automatic cloud transmission

Learners using assistive technology may use equivalent accessible representations without changing the mathematical target.
