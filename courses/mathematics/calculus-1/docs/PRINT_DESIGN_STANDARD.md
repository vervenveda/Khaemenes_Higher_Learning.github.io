# Printable Lesson Design Standard

Every lesson and teacher key uses:
- US Letter print layout with A4-safe margins
- white paper background and dark high-contrast text
- large vector SVG graphs or diagrams
- name and date fields
- six clearly numbered problems
- substantial handwritten-work space
- grayscale-safe color and line-style distinctions
- controlled page breaks
- a matching teacher key with the same figures
- Print / Save as PDF controls

Screen navigation, dark backgrounds, menus, and interactive controls are removed in print. Learners retain corrected worksheets as portfolio evidence.
