Chain Rule with Trigonometric Compositions

The chain rule differentiates a composition by multiplying the rate of the outer function with the rate of the inner function. Clear layer identification prevents missing factors. This lesson emphasizes chain rule with trigonometric compositions through symbolic, graphical, numerical, and contextual evidence.

Learning intentions

  • Define and use the central calculus language in chain rule with trigonometric compositions.
  • Move among symbolic, graphical, numerical, and contextual representations.
  • Show complete reasoning with correct notation, domain conditions, units, and intervals.
  • Verify a conclusion using a second method or representation.

Essential question

How do nested, implicit, and inverse relationships change the way derivatives are calculated and interpreted?

Visual model

The chain rule differentiates a composition by multiplying the rate of the outer function with the rate of the inner function. Clear layer identification prevents missing factors.

\frac{d}{dx}f(g(x))=f'(g(x))g'(x)

Worked reasoning

Layer notationName the outer function and inner function before differentiating.
Multiple layersWork from the outside inward, retaining each unchanged inner expression until its derivative factor appears.

Misconception check: Differentiating only the outer function omits the inner rate and produces the wrong scale.
