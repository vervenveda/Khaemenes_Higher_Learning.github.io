# Khaemenes Open-Age Precalculus & Trigonometry

Repository-ready 36-week course with 92 detailed printable lessons and teacher keys, 13 units, advanced function modelling, a complete trigonometry sequence, vectors, polar and parametric work, sequences, matrices, conics, limits, assessments, projects, records, and local-first progress.

Upload the top-level `precalculus-trigonometry/` folder into `courses/mathematics/`.

Curriculum architect: Jennifer Pearl.
