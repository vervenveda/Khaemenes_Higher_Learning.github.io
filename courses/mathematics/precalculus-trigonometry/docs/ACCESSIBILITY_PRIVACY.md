# Accessibility & Privacy

- Semantic headings, labels, fieldsets, landmarks, keyboard-visible focus, skip links, and responsive layouts
- Reduced-motion support and light/dark themes
- Printable alternatives for interactive work
- SVG figures include titles and descriptions
- Learner progress and assessment attempts remain in local browser storage
- No analytics, advertising, tracking, or remote learner-data submission
- JSON/HTML exports allow families to retain portable records
