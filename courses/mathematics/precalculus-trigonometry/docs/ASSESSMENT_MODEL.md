# Assessment Model

- Diagnostic: 40 prerequisite questions
- Unit mastery: 10 randomized questions per unit, 80% target
- Course bank: 156 validated multiple-choice items with explanations
- Midterm: 60 questions from Units 1–6
- Final: 100 questions across Units 1–13
- Performance evidence: 13 applied investigations and one advanced modelling capstone
- Required practice: written corrections and reassessment when mastery is not demonstrated

The client-side assessment engine stores attempts locally. It is appropriate for learning evidence, not secure high-stakes testing.
