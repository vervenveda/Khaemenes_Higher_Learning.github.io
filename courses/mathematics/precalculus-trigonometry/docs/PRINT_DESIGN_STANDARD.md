# Printable Lesson Design Standard

Every detailed lesson includes a dedicated student print sheet and a separate teacher key.

- US Letter with A4-safe margins
- White paper, dark text, restrained purple/teal/gold accents
- Vector SVG graphs and diagrams
- Two-column six-problem layout with substantial work space
- Name and date lines
- Grayscale-safe labels, dashes, and shapes
- Controlled page breaks
- Screen navigation and buttons removed in print
- Exact forms encouraged before decimal approximations
- Teacher key preserves the same figure and adds answer plus reasoning
