Defining a Researchable Modelling Question

U13 · L01
1

Name the response variable in a model predicting height from age.

Answer: Height
Reasoning: Height is the predicted outcome.
2

What does a positive residual mean?

Answer: Observed value exceeds predicted value
Reasoning: Residual=observed−predicted.
3

Why document assumptions?

Answer: They define when the model is defensible
Reasoning: Assumptions limit interpretation and use.
4

What is interpolation?

Answer: Prediction within the observed data range
Reasoning: It stays inside the fitted domain.
5

What is extrapolation?

Answer: Prediction beyond the observed data range
Reasoning: It extends the model outside evidence.
6

What should a model defense include?

Answer: Choice, parameters, evidence, residuals, limitations, and conclusion
Reasoning: A defensible model connects method, evidence, and scope.
