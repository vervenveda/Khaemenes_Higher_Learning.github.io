# Collegiate Science Course Package Standard

The Science Department uses the same full-course anatomy as Calculus II and Linear Algebra.

## Required top-level files
```
index.html
course-data.js
course-map.json
manifest.webmanifest
service-worker.js
offline.html
README.md
FILE_MANIFEST.md
PROFILE_INTEGRATION_NOTES.md
UPDATE_NOTES.md
UPLOAD_MAP.md
VALIDATION_REPORT.md
SHA256SUMS.txt
```

## Required directories
```
assessments/
assets/
diagnostic/
docs/
records/
teacher/
teacher-keys/
tools/
units/
```

## Science-specific requirements

A completed course should include:
- readiness diagnostic,
- full collegiate lesson sequence,
- matching faculty keys,
- laboratory/investigation work,
- randomized mastery checks,
- cumulative midterm and final,
- formal laboratory notebook/evidence standard,
- scientific vocabulary,
- quantitative analysis and uncertainty,
- portfolio evidence,
- learner profile integration,
- offline support,
- source validation,
- browser interaction validation,
- explicit non-accreditation and transfer-credit boundary language.

A folder scaffold is not a completed course.
