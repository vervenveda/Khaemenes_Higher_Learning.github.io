# BIO 101 Readiness Diagnostic

The diagnostic contains **40 original multiple-choice questions** across five domains:

- scientific reasoning and quantitative biology — 8
- chemistry of life — 8
- cell biology and energetics — 8
- genetics and molecular biology — 8
- evolution and ecology — 8

It is a support/placement instrument only. It does not create official mastery, deny enrollment, or replace Unit 01 learning.

A future browser assessment engine will randomize item order and option positions while preserving the bank, explanations, and learner-scoped record boundary.
