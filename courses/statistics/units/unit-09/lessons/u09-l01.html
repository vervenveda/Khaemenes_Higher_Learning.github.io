Logic of Significance Tests

How do null models, test statistics, p-values, errors, power, and effect sizes support disciplined decisions?

Core structure

p-value=P(result at least as extreme|null)

Translating a claim into null and alternative hypotheses and measuring incompatibility with the null. Attend to data source, design, variable type, assumptions, uncertainty, effect size, practical context, and whether the evidence supports description, prediction, generalization, or causation.

Vocabulary: null hypothesis, alternative, test statistic, p-value, significance, Type I error, Type II error, power, effect size.

Use the visual as an evidence display, not decoration. Labels, scales, uncertainty, and context must remain visible.

Worked reasoning

Follow the statistical argument, not only the calculation.

Example 1

Interpret p=0.03.

Assuming the null model is true, results at least this incompatible with the null would occur about 3% of the time; it is not the probability the null is true.

Example 2 · Error analysis

Identify a common error in Logic of Significance Tests.

A common error is to report a calculation without identifying the population, design, assumptions, uncertainty, context, or limits on causal and generalizing claims.

Which statement best describes the central reasoning in Logic of Significance Tests?

Use translating a claim into null and alternative hypotheses and measuring incompatibility with the null; identify the cases, variables, population, design, assumptions, and uncertainty; then interpret the result in context without exceeding what the design supports.

Which practice best verifies work in Logic of Significance Tests?

A defensible analysis checks data quality and design, shows the calculation or simulation, examines diagnostics, reports uncertainty and effect size where relevant, and states limitations.
