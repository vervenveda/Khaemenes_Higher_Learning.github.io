Core structure

power=1−β

Connecting α, β, power, effect size, variability, and sample size. Attend to data source, design, variable type, assumptions, uncertainty, effect size, practical context, and whether the evidence supports description, prediction, generalization, or causation.

Vocabulary: null hypothesis, alternative, test statistic, p-value, significance, Type I error, Type II error, power, effect size.

Use the visual as an evidence display, not decoration. Labels, scales, uncertainty, and context must remain visible.

Worked reasoning

Follow the statistical argument, not only the calculation.

Example 1

What raises power while holding other factors fixed?

A larger sample, larger true effect, smaller variability, or larger α raises power.

Example 2 · Error analysis

Identify a common error in Errors, Power and Study Planning.

A common error is to report a calculation without identifying the population, design, assumptions, uncertainty, context, or limits on causal and generalizing claims.
